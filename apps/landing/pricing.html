Honest note on what changes between tiers: Basic, Pro, and Elite are real, separately priced plans you can subscribe to inside the app today. As of this writing, the app does not yet gate any specific feature behind a paid tier — every plan currently unlocks the same core functionality (training, nutrition, recovery, AI coach, professional guidance, progress tracking) described on the Features page. We're not going to invent a feature comparison that doesn't exist yet — if you're deciding which plan to pick, price is currently the only real difference. Cancel any time — cancellation takes effect at the end of your current billing period, not immediately, so you keep access you've already paid for.
