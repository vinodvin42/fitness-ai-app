Where the images come from

Program and Recipe artwork: Unsplash, under the Unsplash License — free for commercial use, no attribution required. Unsplash+ photos are deliberately excluded.

Exercise demonstration photos and their instruction steps: free-exercise-db, public domain under the Unlicense.

How they are stored

They aren't. There is no object storage in this build, so every image is a plain URL on the row — the same shape Exercise.mediaUrl has always had. The apps treat a missing or broken image as optional and fall back to the icon tile they used before.

Re-running it

The Seed content to Azure workflow re-seeds production on demand. Every write is a stable-id upsert, so it is safe to run repeatedly, and it runs content-only — it can never touch the admin or coach accounts.
